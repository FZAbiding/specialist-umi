# 证据与数据规则

1. 区分官方源码事实、本机软件检查、合成几何、模拟器结果、真实相机采集、实体执行和外部精度真值。每条结论引用对应来源或结构化证据，不互相替代。
2. 记录日期、源提交/版本、命令、输入哈希、参数、输出位置、退出状态及适用范围。报告是解释，reports/evidence是摘要，logs保留完整大产物。
3. 原始INSV不改写；裁剪、窗口裁定、重建和动作导出都生成派生文件并记录依据。有效窗口之外不补造手部状态；缺未来目标的动作不以零填充。
4. world坐标和TCP定义必须明确；数学往返误差不是物理定位误差。像素重投影低也不能证明米制尺度正确。机械臂标定、IK或闭环执行未完成时保持待验。
5. 仿真/合成数据在文件和说明中标记；固定随机种子。当前真实数据只有单右手，合成双手测试不能称为双机采集验收。
6. Git不包含录像、实拍截图、RRD、权重或本机私有硬件标定。报告中的logs路径是可选的本地复现链接；源码、受版本管理的资产和证据链接必须存在。tools/verify_report.py默认适用于新克隆，--require-local-data用于本机严格核查。
7. 外部源码只保存核读URL、提交与哈希；不把第三方方法当作本地实测。官方参考PDF原件保留来源、页数、尺寸和哈希；教学Tag位图的来源与许可见reports/assets。
8. 候选报告不等于正式发布；Git提交/推送以实际命令结果和远端HEAD为准，不提前写成功。默认不导出PDF或自动部署。
